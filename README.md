# Dreamer Letter Generator

写信、排版、导出成图。在信纸底图上排中英文混排的信件，实时预览，导出 PNG / JPG。

## 用法

打开 `index.html` 就能用，不需要装任何东西、不需要联网构建。

左边分四页：

| 页 | 内容 |
|---|---|
| 信件 | 抬头、正文、英文译文、署名，每块可单独设对齐和字号 |
| 排版 | 字号、行距、段间距、字间距；文字区域四边；整体靠上/中/下 |
| 字体 | 中文字体、英文字体、墨色、浓淡 |
| 素材 | 上传自己的字体和信纸底图 |

右边是预览，实时更新，可缩放。导出在顶栏右侧。

## 几个设计上的取舍

**中英文字体是同时生效的。** 一句话里的汉字用中文字体画，字母和数字用英文字体画，逐字符判断后分段渲染。不能靠 CSS 的 `font-family` 回退，因为中文花体字体往往自带一整套英文字形，浏览器会直接用它，导致英文字体选了没反应。

**换底图后要重新框文字区域。** 画布尺寸跟着右页底图的原始尺寸走，所以换成别的比例的图也不会变形。但文字区域是按百分比定的，换图后需要到「排版 → 文字区域」把四条边对准新底图的空白处，勾上「显示区域参考框」会好对一些。参考框只在预览里，不会印进导出的图。

**导出倍率会被自动压制。** 浏览器对单张画布的总像素有上限（Safari 最紧），跨页 3 倍会超。超了会自动降到安全范围，顶栏的尺寸提示里会说明。

**本地保存有容量上限。** 浏览器给每个站点的本地存储大约 5 MB。存不下时会分级降级：先丢字体，再丢底图，设置和文字一定保住。左下角状态栏会如实说明存到了哪一级。中文字体通常 5–10 MB，大概率存不进去，每次要重传；英文花体一般一两百 KB，能存下。

## 本地保存

所有内容和设置自动存在浏览器里，关掉再打开原样回来。左下角「重置」是两段式确认：点一下变红，四秒内再点一次才真的清空。

## 结构

```
dreamer-letter/
  index.html        单文件，底图以 base64 内嵌，因此可以直接双击打开
  assets/           底图原图，方便替换或二次编辑
```

线上地址：https://akihowaito.github.io/club/dreamer-letter/

底图内嵌而不是走相对路径，是因为用 `file://` 打开时，相对路径加载的图片会污染 canvas，导出会直接抛 SecurityError。内嵌之后本地和线上都能正常导出。
