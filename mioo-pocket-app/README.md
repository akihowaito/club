# 咪呜电竞 · MIOO POCKET CLUB

测试页面：https://akihowaito.github.io/club/mioo-pocket-app/

这里是 Vue 3 + Vite 项目的静态发布文件。通过 `npm run build:pages` 构建，使用 `?view=menu`、`?view=events`、`?view=gifts` 和 `?view=mine` 切换页面，支持 GitHub Pages 直接访问和刷新。

2026-10-06 发布：保留现有品牌素材和当前页面样式，包含导航选中图标的柔光效果。咨询草稿与收藏保存在当前浏览器，订单咨询需要联系客服。
