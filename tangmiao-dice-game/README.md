# 糖喵电竞 · 骰子互动网页

## 测试口令
`TANGMIAO0913`

该口令为测试口令，可无限重复掷骰，方便测试动画、历史记录与截图下载。

## 正式一次性演示口令
`TOMIA2026ONCE`

正式演示口令会在当前浏览器设备中记录为已使用，仅可掷一次。

## 已实现
- 完整 HERO 原图显示，不裁切
- HERO 慢速扫光与微光动画
- 3D 骰子翻滚、音效、震动、粒子特效
- 桌面端主要组件 Hover 交互
- 测试口令无限次数
- 正式口令一次性限制（纯前端演示逻辑）
- 掷骰后自动生成并下载 PNG 结果截图
- 截图包含时间、设备信息、兑换码、点数、记录编号
- 历史骰子记录，仅提供查看截图
- 下单、赔付、权益须知顶部预览与原图查看
- 手机端响应式布局

## 注意
当前仍为纯前端版本。正式口令的一次性限制使用浏览器 localStorage，无法防止用户换设备、换浏览器或清除网站数据后再次使用。若商业正式使用，需要把兑换码验证与使用状态放到服务器端。
